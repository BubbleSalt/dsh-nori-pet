# Nori 桌宠（dsh 插件）

> 把 dsh 的长时间输出变成**听得到的结论**，再配上一只有形象、有声音、有脾气的桌宠。

模型、声线、人设都是第三方授权资产，**不随仓库分发**——仓库只提供契约与降级路径，你自备资产即可运行。

> **适用版本**：v0.4.0　｜　**最后更新**：2026-10-23

---

## ✨ 它解决什么

dsh 一次回答可能是三千字的报告，而中文朗读只有约 5 字/秒 —— 逐句念要十分钟。Nori 的取舍是：

- **短回答**：逐句详读，像有人在旁边给你复述
- **长回答**：先读开头两句，剩下的压成一两句结论（细节留在屏幕上）

## 🖱 你能做什么

拖她、揉她的头、让她睡着、调她的体型、打开设置面板改配置 —— 交互细节见 [架构与目录](docs/architecture.md)。

## 🚀 快速开始

```powershell
# 1. 克隆
git clone <repo> dsh-nori-pet; cd dsh-nori-pet

# 2. 放资产到对应目录（都可以留空，缺什么降级什么）
#    Nori_web/   Live2D 模型     voice/   声线 wav
#    persona/    prompt.txt（人设，自备）

# 3. 安装：探测资产 → 构建 → 装配进 dsh → 写配置
.\install.ps1

# 4. 打开/刷新 dsh 网页（模型是静态资产，Ctrl+F5 强刷）
```

没有模型 → 进入**纸片人模式**（气泡 + 语音正常，表情/动作不可用）；没有声线 → 静音但气泡照常。
完整步骤与 GPT-SoVITS 部署见 **[安装与资产准备](docs/setup.md)**。

## 📦 需要自备的资产

| 资产 | 放哪 | 缺了会怎样 |
|---|---|---|
| Live2D 模型（任意 Cubism4） | `Nori_web/` 或配置 `model.file` | 纸片人模式：气泡 + 语音正常，表情/动作不可用 |
| 声线样本 wav | `voice/` | 能动能说话气泡，但没有声音 |
| 人设文本 `prompt.txt` | `persona/`（不入库） | 改写层自动关闭，直接朗读原文 |
| GPT-SoVITS 服务 | 仓库外 | 语音不可用，其余正常 |

改写任务指令（`persona/reframe.txt`）与概括规则（`persona/summary.txt`）随仓库提供。

完整说明见 [架构与目录](docs/architecture.md)。

```
src/            宿主：路由、朗读管线、改写层、TTS、配置读写
src/client/     前端：Live2D 渲染、气泡、朗读队列、设置面板
persona/        改写与概括规则（人设 prompt.txt 需自备）
scripts/        安装 / 回归 / 工具脚本
docs/           面向使用者的文档（入库）
devlog/         开发过程稿（不入库）
```

## 📜 许可与第三方资产

本仓库**不含**任何第三方授权资产（Live2D 模型、声线、人设文本）。代码以仓库声明的许可证发布；
使用 Nori 的形象/声线/人设需自行取得授权。细节见 [模型契约](docs/model-contract.md) 与 [运维与排障](docs/operations.md)。
