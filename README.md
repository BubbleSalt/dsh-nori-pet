# Nori 桌宠（dsh 插件）

> 把 dsh 的长时间输出变成**听得到的结论**，再配上一只有形象、有声音、有脾气的桌宠。

模型、声线、人设都是第三方授权资产，**不随仓库分发**——仓库只提供契约与降级路径，你自备资产即可运行。

> **适用版本**：v0.4.0　｜　**最后更新**：2026-10-23

## ✨ 它解决什么

dsh 一次回答可能是三千字的报告，而中文朗读只有约 5 字/秒 —— 逐句念要十分钟。Nori 的取舍是：

- **短回答**：逐句详读，像有人在旁边给你复述
- **长回答**：先读开头两句，剩下的压成一两句结论（细节留在屏幕上）

### 功能一览

- **Live2D 立绘常驻**：浏览器角落的 Nori，回话时张嘴、眨眼、跟情绪换表情；带睡眠与摸头小交互
- **Nori 声线朗读**：agent 输出经本地 GPT-SoVITS 合成 Nori 声线，音量实时驱动口型（唇同步）
- **改写层（Nori 口吻）**：LLM 把输出改写成 Nori 的说话方式再朗读；可开关、可换模型，内置防幻觉（不虚构未发生的事）
- **流式分批低延迟**：句子成句即改写广播，长 turn 中途就开始播，不用等整轮结束；顺序不乱、不重排、不劈英文词
- **中英混排保护**：自动在中文与英文词之间补逗号、清反引号，避免 AR 对齐跳字/吞句（读出率实测 ~25% → ~90%+）
- **ttsWatch 守护**：GPT-SoVITS（9880）掉线后自动拉起
- **权限申请播报**：agent 请求权限时**打断当前朗读**、优先播报"有权限申请：工具。原因：…"（原文播报、不走改写），并切惊讶表情提醒你回来处理
- **一键部署**：`install-sovits.ps1` 可顺手装 GPT-SoVITS；`install.ps1` 首次交互引导配置
- **设置面板**：⚙ 图形化改全部配置，不用手改 JSON
- **安全边界**：仅放行本地来源；路径穿越 403；body 上限 16KB；会话维度 WS 过滤

## 🖱 交互操作

- **移动位置**：按住她的身体拖动，松手即固定，位置自动记住；**双击**回到默认角落
- **放大缩小**：点 `＋ / －` 按钮，或在身上滚轮缩放；比例同样自动记忆
- **调整体型**：点 ⚙ 打开设置面板，顶部常驻滑杆调「整体缩放 / 少女体型 / Q版」，实时生效
- **摸头**：在她**头部**按住并来回摩擦一小会，会触发摸头台词和表情反应（头部优先，不会误拖）
- **睡眠**：90 秒没有交互会自己睡着（闭眼），戳她一下就醒
- **穿透画布**：除角色占位与热区外，透明区域不挡页面文字选取

## 🚀 快速开始

```powershell
# 1. 克隆
git clone <repo> dsh-nori-pet; cd dsh-nori-pet

# 2. 放资产到对应目录（都可以留空，缺什么降级什么）
#    Nori_web/   Live2D 模型     voice/   声线 wav
#    persona/    prompt.txt（人设，自备）

# 3. 安装：探测资产 → 构建 → 装配进 dsh → 写配置
.\install.ps1

# 4. 打开/刷新 dsh 网页（模型是静态资产，Ctrl+F5 强刷）
```

没有模型 → 进入**纸片人模式**（气泡 + 语音正常，表情/动作不可用）；没有声线 → 静音但气泡照常。
完整步骤与 GPT-SoVITS 部署见 **[安装与资产准备](docs/setup.md)**。

## 📦 需要自备的资产

| 资产 | 放哪 | 缺了会怎样 |
|---|---|---|
| Live2D 模型（任意 Cubism4） | `Nori_web/` 或配置 `model.file` | 纸片人模式：气泡 + 语音正常，表情/动作不可用 |
| 声线样本 wav | `voice/` | 能动能说话气泡，但没有声音 |
| 人设文本 `prompt.txt` | `persona/`（不入库） | 改写层自动关闭，直接朗读原文 |
| GPT-SoVITS 服务 | 仓库外 | 语音不可用，其余正常 |

改写任务指令（`persona/reframe.txt`）与概括规则（`persona/summary.txt`）随仓库提供。
